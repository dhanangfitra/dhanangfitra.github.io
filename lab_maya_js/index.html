    📖 Panduan Lab Maya JavaScript
    
    
    
      
      
        
    1. Tekan Mulai, lalu isi Nama dan Kelas. Identitas terkunci sampai semua latihan selesai.
      2. 
        
    2. Pilih soal (1–15). Baca tujuan latihan dan kode yang harus diketik.
      3. 
        
    3. Ketik ulang kode di editor. Copy, cut, dan paste dinonaktifkan agar kamu terbiasa menulis kode sendiri.
      4. 
        
    4. Tekan ▶ Jalankan (atau Ctrl+Enter). Jika program memakai prompt(), isi kotak input yang muncul. Hasil console.log(), alert, prompt, dan error tampil di tab Console.
      5. 
        
    5. Tab Contoh Target menampilkan hasil program yang benar, dijalankan otomatis dengan data uji.
      6. 
        
    6. Tekan ✔ Cek Kode. Pemeriksa menjalankan programmu dengan data uji (input prompt, mengisi form, mengklik tombol). Tanda ✓ benar, ✗ salah. Klik tanda ✗ atau error di Console untuk langsung menuju baris kodenya.
      7. 
        
    7. Jika benar, tekan 📷 Simpan JPG. Setelah semua soal selesai, baca ringkasan materi, isi umpan balik, dan simpan JPG bukti penyelesaian.
