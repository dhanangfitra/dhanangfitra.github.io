    📖 Panduan Lab Maya HTML
    
    
    
      
      
        
    1. Tekan Mulai, lalu isi Nama dan Kelas pada panel Daftar Latihan. Identitas ini ikut tercetak di gambar JPG.
      2. 
        
    2. Pilih latihan (1–10). Baca tujuan latihan dan kode yang harus diketik.
      3. 
        
    3. Ketik ulang kode di editor. Fitur copy, cut, dan paste dinonaktifkan agar kamu terbiasa menulis tag HTML sendiri.
      4. 
        
    4. Hasil kode tampil otomatis di simulasi browser. Gunakan tab Contoh Target untuk membandingkan dengan tampilan yang benar.
      5. 
        
    5. Tekan ✔ Cek Kode. Tanda ✓ hijau berarti benar, tanda ✗ merah berarti masih ada yang harus diperbaiki.
      6. 
        
    6. Jika semua benar, tekan 📷 Simpan JPG untuk menyimpan tangkapan layar kode program dan hasil di browser localhost. Tempelkan gambar itu di lembar jawaban.
      7. 
        
    7. Pekerjaanmu tersimpan otomatis di perangkat ini, jadi kamu bisa melanjutkan nanti.
